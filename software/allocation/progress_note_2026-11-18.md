## Research Summary (2–4 useful techniques)

### 1. Adjustable viewpoint allocation with forward/backward ray tracing (Optics Letters, 2024)
- **Key takeaway**: Synthetic image (SI) is first generated by backward ray tracing from desired viewing distance and viewpoint interval. Forward ray tracing then corrects positional deviations between actual and ideal viewpoints. This reallocates information density on the SI, suppresses inter-view crosstalk, and eliminates artifacts in adjacent zones, thereby expanding the usable viewing angle.
- **Relevance**: Direct software allocation method. Given tracked eye positions, compute ideal viewpoint targets, then adjust the mapping to minimize crosstalk for multiple simultaneous viewers. Supports non-uniform density (more views near primary viewers).
- **Reference**: Li et al., Opt. Lett. 49, 6133–6136 (2024). DOI: 10.1364/OL.537865

### 2. Subpixel-demultiplexing viewpoint-interleaving encoding (SVE) (PhotoniX, 2026)
- **Key takeaway**: Dual assignment strategies on multiplexed panels produce an aliasing-free high-density subpixel array (effective 4320×3840). Odd–even vertical viewpoint interleaving improves parallax smoothness and visual comfort across the full FOV. Combined with full-field dual-plane lens optimization, yields ~2.67–2.99 lp/mm spatial and 1.45 VIPD angular resolution on a 5.5-inch prototype.
- **Relevance**: Practical interleaving pattern for mapping allocated views onto commercial panels. Vertical interleaving reduces discontinuities when multiple viewers move laterally.
- **Reference**: PhotoniX 7, 73 (2026). DOI: 10.1186/s43074-026-00292-w

### 3. Performance characterization framework via ray-phase space (PhotoniX, 2026)
- **Key takeaway**: Models light-field propagation in ray-phase space (rooted in the plenoptic function) to predict crosstalk-free viewing-zone boundaries, depth-dependent spatial-resolution degradation, and space-bandwidth-product feasible domains. Validated on a 31.5-inch 8K crossed-lenticular prototype; measured viewing limits and resolution trends match theory (R² ≈ 0.86).
- **Relevance**: Quantitative guide for allocation decisions. Use predicted crosstalk-free zones and depth-resolution curves to decide how many discrete views to assign per tracked viewer and where to place them.
- **Reference**: Liu et al., PhotoniX 7, 62 (2026). DOI: 10.1186/s43074-026-00286-8

### 4. Freeform directional backlight multi-viewer autostereoscopic display (Displays, 2026)
- **Key takeaway**: Continuous freeform backlight + eye-tracking delivers full native panel resolution to multiple simultaneous viewers (~44° FOV on 27-inch prototype, average crosstalk <7.1 % single / <8.8 % three-viewer). Illumination path is decoupled from image content for independent binocular modulation.
- **Relevance**: Hardware-assisted light-cone allocation. Software allocation layer mainly selects the correct left/right image pair per tracked viewer and synchronizes with the directional backlight control.
- **Reference**: Displays 95, 103581 (2026). DOI: 10.1016/j.displa.2026.103581

## Code Scaffold / Pseudocode Note

Existing scaffold (`view_allocation_scaffold.py`) remains the base. Minimal extension for the adjustable-allocation idea:

```python
# Pseudocode: adjustable viewpoint allocation (inspired by Li et al. 2024)
def allocate_views(tracked_eyes, num_views, view_interval_deg):
    # Backward: compute ideal SI mapping from desired viewing geometry
    ideal_assignments = backward_ray_trace(tracked_eyes, view_interval_deg)
    # Forward: correct actual ray positions and re-weight density
    corrected = forward_ray_trace(ideal_assignments)
    # Optional: apply odd-even vertical interleave (SVE-style)
    for a in corrected:
        a.interleave_offset = a.viewer_id % 2
    return corrected  # list of (viewer_id, left_idx, right_idx, offset)
```

The current scaffold already returns `ViewAssignment` objects with indices and interleave offsets; the above can be dropped in as a refinement step.
