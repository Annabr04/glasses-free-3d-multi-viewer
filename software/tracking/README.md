# Tracking

Multi-person face and eye tracking, pose estimation, prediction, and sensor fusion for multi-viewer glasses-free 3D systems.

This component provides real-time 3D positions of viewers’ eyes so that the allocation and content layers can generate correct views.

## Contents

- `progress_note_2026-11-09.md` — Research summary of recent advances in multi-person tracking, gaze estimation, and related techniques for autostereoscopic displays.
- `multi_viewer_tracker_scaffold.py` — Minimal Python scaffold for multi-face/eye detection, simple association, and short-horizon prediction.
